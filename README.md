## Atividade 3: Sensor de Presença (PIR) com LED

O projeto utiliza um sensor de presença infravermelho passivo (PIR) como entrada para controlar um LED como saída. Ao detectar movimento no ambiente, o sensor envia um sinal ao Arduino, que aciona o LED como sinalizador visual.

* O Arduino lê o sinal do sensor PIR pelo **pino 7**
* Controla o LED pelo **pino 2**
